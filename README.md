# Site do Pace Run

Páginas públicas do app (exigidas pelas lojas): início, política de privacidade, termos de uso e suporte.
Publicado com GitHub Pages a partir do repositório público `pace-run-site`.

- Edite os textos em `build.py` e rode `python3 build.py` para gerar os `.html`.
- Antes de publicar na loja, preencha `[NOME DO RESPONSÁVEL]` e `[CIDADE/UF]` (constantes `OWNER` e `CITY`).
